# @adam/portfolio-sanity

GROQ queries and generated TypeScript types for the portfolio Sanity studio. The studio in `apps/studio` owns the schema. The site in `apps/site` uses this package. It is a private workspace package. It is not published.

The package ships TypeScript source. There is no build step. Vite compiles it inside the site.

## Usage

```ts
import {
  RESUME_QUERY,
  COVER_LETTER_QUERY,
  PORTFOLIO_GALLERY_QUERY,
  type RESUME_QUERY_RESULT,
  type COVER_LETTER_QUERY_RESULT,
  type PORTFOLIO_GALLERY_QUERY_RESULT
} from '@adam/portfolio-sanity';

const resume = await client.fetch<RESUME_QUERY_RESULT>(RESUME_QUERY, { slug: 'portfolio' });
const letter = await client.fetch<COVER_LETTER_QUERY_RESULT>(COVER_LETTER_QUERY, { id });
const gallery = await client.fetch<PORTFOLIO_GALLERY_QUERY_RESULT>(PORTFOLIO_GALLERY_QUERY, { slug: 'best-showcase' });
```

## Files

| File              | Edit by hand? | Purpose                                                                         |
| ----------------- | ------------- | ------------------------------------------------------------------------------- |
| `queries.ts`      | Yes           | The three GROQ queries. TypeGen reads this file.                                |
| `sanity.types.ts` | No            | Generated by `pnpm typegen` from the studio schema and `queries.ts`. Commit it. |
| `mod.ts`          | Yes           | The public surface: the three queries and the three result types.               |

| Query                     | Result type                      | Fetches                                                                 |
| ------------------------- | -------------------------------- | ----------------------------------------------------------------------- |
| `RESUME_QUERY`            | `RESUME_QUERY_RESULT`            | A resume by slug, with logo, contactInfo, experience, education, skills |
| `COVER_LETTER_QUERY`      | `COVER_LETTER_QUERY_RESULT`      | A cover letter by `_id`, with logo and contactInfo                      |
| `PORTFOLIO_GALLERY_QUERY` | `PORTFOLIO_GALLERY_QUERY_RESULT` | A portfolio gallery by slug, with each piece and its image URLs         |

## Change a query or the schema

1. Edit the schema in `apps/studio/schemaTypes/` and the query in `queries.ts`.
2. Run `pnpm typegen` from the repository root.
3. Run `pnpm build` and `pnpm check`. The site type-check finds a broken field.

A rename or removal of a field that a query reads breaks the site. Both apps are in this repository, so one pull request holds the schema, the query, the types, and the site change.
